## 2. 핵심 개선점
- **한눈에 이해**: 상단 요약 카드에서 최종 예측/동의/확률/신뢰도를 즉시 확인.
- **해석 신뢰도 규칙화**: 3모델 동의 + 평균확률 >= 90% → 높음, 2개 이상 동의 +
  70% 이상 → 보통, 그 외 제한적. (`src/llm/chat.py: summarize_prediction`)
- **AI 설명은 결과처럼**: LLM 프롬프트 원문 대신 규칙 기반 자연어 설명을 노출
  (`generate_user_explanation`). 예: "이 샘플은 3개 모델 중 3개가 LUSC 로 예측했으며
  ... 근거 문서가 정리된 유전자는 8/18개이며 나머지는 근거 정리 전이라 생물학적
  설명은 제한적입니다."
- **개발자 문구 은닉**: `TODO(evidence_needed)` 는 화면에 절대 노출하지 않고, draft
  유전자는 "아직 근거 정리 전입니다" 로 안내. curated 문서만 섹션 내용을 표시.
- **RAG Chat**: 예시 버튼(왜 예측됐어 / 어떤 gene 중요 / 근거 충분 / 임상 사용 가능)
  + 자유 입력. 규칙 기반으로 라우팅(`answer_question`), 임상 질문에는 명확히 "불가".

## 3. 신규/수정 파일
- 신규: `src/llm/chat.py` — `summarize_prediction`, `generate_user_explanation`,
  `answer_question` (규칙 기반, LLM API 미호출, 파일 I/O 없음).
- 수정: `app.py` — 전체 한국어 사용자 화면으로 재작성. 기존 기능(예측/근거/설명)은
  유지하되 표시 방식만 사용자 친화적으로 변경. LLM 프롬프트 원문 표시 제거.
