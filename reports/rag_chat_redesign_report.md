# RAG Chat 재설계 보고서 — 암종별 유전자 근거 대화형 설명

_목표: "암종 예측 결과에 대해, 모델이 중요하게 본 유전자와 RAG 근거를 대화형으로
설명하는 시스템". 유전자를 '원인' 으로 단정하지 않고 '관련 유전자/근거 후보' 로
표현하며, 근거가 있을 때만 기능·암 관련성을 설명한다._

## 1. 무엇을 바꿨는지
- **암종별 유전자 후보 중심으로 전환**: 기존에는 전체 consensus 유전자만 표로
  보여줬으나, 이제 **예측 암종의 per-class Top gene**
  (`reports/top_genes_by_model.csv`의 `scope==per_class & cancer_type==예측암종`)을
  가져와 "현재 예측 암종에 대한 유전자 후보"로 보여줍니다. 근거 문서가 있는 유전자를
  먼저 노출합니다.
- **`app.py` 사용자용 재구성 + 탭**: `📊 예측 요약` 카드(예측 암종 / 모델 동의 /
  주요 유전자 후보 / 근거 상태) 아래에 두 개의 탭:
  - `🔬 예측 & 유전자 근거`: AI 설명(규칙 기반), 모델별 예측표, 암종별 유전자 후보표,
    선택 유전자 근거 문서.
  - `💬 RAG Chat`: 예시 질문 버튼 + `st.chat_input` 대화.
- **`src/llm/chat.py` 재작성**: `answer_question(question, context)` 를 RAG·암종
  인지형 규칙 기반으로 구현. 질문에서 유전자 심볼을 감지해 해당 근거 문서를
  조회하고, 근거가 없으면 "근거 제한적" 으로 답합니다. (실제 LLM API 미호출)
- **THCA 근거 유전자 corpus 추가(curated)**: `TG`, `TPO`, `TSHR` 문서를 공개 DB
  (GeneCards/NCBI Gene/UniProt) 출처와 함께 한국어로 작성. 이 3개는 실제로 로지스틱
  회귀의 THCA per-class 상위 유전자(OTOS, **TPO, TSHR, TG**, RMST)에 포함되어 있어,
  "모델이 갑상선 마커를 짚었고 RAG로 그 근거를 설명"하는 스토리가 성립합니다.
- **표현 원칙 코드화**: 설명/답변에서 "모델이 암종 구분에 중요하게 본 유전자",
  "관련 유전자", "근거 후보" 로 표기하고, 인과(원인) 단정을 피합니다.

## 2. 어떤 질문에 답할 수 있는지
`answer_question(question, context)` 이 처리하는 범주(예: 갑상선암 샘플):

| 질문 유형 | 예시 | 답변 요지 |
|---|---|---|
| 예측 이유 | "왜 갑상선암으로 예측됐어?" | 모델 동의/평균확률/해석 신뢰도 |
| 중요 유전자 | "어떤 유전자가 중요했어?" | 암종별 후보 나열 + "원인 아님/관련 후보" 명시 |
| 유전자 근거 | "TG/TPO/TSHR은 어떤 근거가 있어?" | 각 유전자 RAG 근거(기능·암 관련성) 요약, 없으면 근거 제한적 |
| 인과 vs 신호 | "이 유전자가 원인이야, 아니면 관련 신호야?" | "구분에 유용한 관련 신호이며 원인 증명 아님" |
| 근거 충분성 | "근거가 충분해?" | curated 유전자 수 + 근거 상태(충분/제한적/작성중) |
| 임상 사용 | "임상적으로 써도 돼?" | "불가 — 연구/교육 목적" |
| 기타 | (그 외) | 답변 가능한 질문 예시 안내 |

실제 검증 응답(THCA 샘플, 3모델 THCA 동의, 평균 99.6%):
- "TG/TPO/TSHR은 어떤 근거가 있어?" → TG=티로글로불린(갑상선호르몬 전구체) 등 각
  유전자 기능 + 암종 관련 근거를 한국어로 제시.
- "근거가 충분해?" → "근거 문서가 정리된 유전자는 SFTPB, TPO, TSHR, TG, 근거 상태
  '충분'".

## 3. 아직 근거가 부족한 gene
- **THCA 후보 중 근거 문서 없음**: LASS3, OTOS, HPX, TRIM10, LOC100130933,
  PCDHA11 등(모델은 지목했으나 corpus 미작성 → "근거 제한적").
- **corpus 전체 draft(근거 정리 중) 10개**: ANKRD43, C1orf106, FAM150B, LIX1,
  LOC145837, NOVA1, PRR15L, RIC3, SCN4A, SYT1.
- **curated 완료(11개)**: SFTPB, GPRC5A, LUM, HOXC6, MT1H, RGN, PRODH, CYP2S1
  (overall consensus) + TG, TPO, TSHR (THCA 마커).
- 다른 암종(BRCA/LUAD/LUSC/KIRC/COAD)의 per-class 후보는 일부만 근거가 있어,
  현재 가장 근거가 탄탄한 데모 암종은 **THCA** 입니다.

## 4. 검증 결과 (Streamlit AppTest, THCA 샘플)
- **예외 0개 (CLEAN)**, 탭 2개, 챗 예시 버튼 5개 정상.
- 암종별 유전자 후보표: `SFTPB, TPO, TSHR, TG, LASS3, OTOS, ...` — 근거 있는
  유전자(TG/TPO/TSHR/SFTPB)가 먼저 표시됨.
- 챗 버튼 클릭 시 규칙 기반 답변 렌더링 확인.
- **비노출 확인**: `TODO(evidence_needed)`, LLM 프롬프트(`[SYSTEM]`/`[USER]`),
  영어 섹션 헤더(`## summary`/`## pathway`)가 화면에 나타나지 않음.
